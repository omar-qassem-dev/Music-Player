# 🎵 Music Player

A modern and responsive **Music Player** built using **HTML , CSS , and JavaScript** .

The project provides a clean and interactive music-player interface with playback controls , playlist management , shuffle and repeat modes , progress seeking , volume control , and responsive design .

## ✨ Features

* ▶️ Play / Pause
* ⏮️ Previous / ⏭️ Next
* 🔀 Shuffle
* 🔁 Repeat
* 🎚️ Progress & volume control
* ⏱️ Current time & track duration
* 📋 Dynamic playlist
* 🖼️ Dynamic album artwork
* 📱 Responsive design
* ✨ Modern dark UI
* ♿ Basic accessibility support

## 🛠️ Technologies Used

* HTML
* CSS
* **JavaScript
